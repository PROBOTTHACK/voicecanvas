# Design System

Premium, minimal, professional creative tool. Not a chatbot dashboard, generic SaaS admin, AI playground, or canvas demo.

## Colors
| Element | Value |
|---|---|
| App background | `#111111` |
| Canvas surface | `#FFFFFF` |
| Primary accent | `#6366F1` |
| Success | `#22C55E` |
| Primary text | `#FFFFFF` |
| Secondary text | muted neutral gray |
| Borders | subtle dark gray |

## Layout
- **Header:** logo, document name, save status, undo, redo, export, account
- **Left sidebar:** select tool, shapes, text, other tools, layers access/list
- **Center:** canvas, zoom controls, navigation, selection/manipulation; canvas centered
- **Right panel:** contextual — document props when nothing selected; object props when selected (position, width, height, rotation, fill, stroke, opacity, corner radius, typography)

## Voice bar
Prominent but non-dominating floating bar: mic button, listening indicator, waveform, transcript, processing indicator, execution feedback.

## Interaction
Subtle borders, consistent spacing, rounded panels, clear hierarchy, smooth transitions, restrained accent, minimal icons, clear hover/active states. Avoid heavy gradients, effects, distracting animation. Canvas stays the focus.
