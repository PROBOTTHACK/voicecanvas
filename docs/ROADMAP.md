# Roadmap

Initial plan, not a fixed commitment — reassess estimates as complexity appears.

| Phase | Focus |
|---|---|
| Sprint 1 — Editor Foundation | Frontend setup, editor UI, Fabric integration, shapes, text, manipulation, state sync |
| Sprint 2 — Voice Infrastructure | Push-to-talk UI, speech recognition, transcription, FastAPI comms, cloud LLM, structured command generation, first voice-created rectangle |
| Week 3 — AI Command Engine | Command registry, schema validation, shape/text creation, property modification, error handling, execution feedback |
| Week 4 — Spatial Intelligence | Object references, context-aware selection, relative positioning, alignment, centering, distribution |
| Week 5 — Groups & Typography | Group/ungroup, group selection/editing, font changes, weight, letter spacing, typography recommendations |
| Week 6 — History & Persistence | Undo/redo, command history, persistence, project saving, PNG/SVG/PDF export |
| Weeks 7–8 — Polish | Complex voice instructions, ambiguity handling, error recovery, design recommendations, UI polish, performance, E2E tests, public prototype |

## Sprint 2 first milestone
Say "Create a red rectangle with width 350 and height 400 pixels" and see it appear. Support only a small command set first.
